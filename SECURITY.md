# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email [adamlockhart12@gmail.com](mailto:adamlockhart12@gmail.com) with:

- A description of the vulnerability
- Steps to reproduce the issue
- Any relevant logs or screenshots

I will acknowledge receipt within 72 hours and provide an estimated timeline for a fix.

## Scope

This policy applies to the xoxo desktop application and its server component. Third-party dependencies are managed via Dependabot and updated regularly.
